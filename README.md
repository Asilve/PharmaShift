# PharmaShift
A desktop application that manages Employee shifts, holidays and displays they hours and expected pay in a scheduled display for Invoice checking purposes.

## Scope
This app will allow users to:
- Create Employee weekly schedules with the addition of shifts they work for each day. These shifts include Location, Rate and either a time frame or number of hours worked depending on work type.
- Delete and edit the Employee work schedules on demand.
- Add, remove and edit Employee holidays into the system.
- Create and view a schedule of what the employee should be working for a specified period of time with the pay they should expect, dynamically updated using the holidays the user inputted.
- Extract the schedules as a pdf for sharing purposes.
- Save and load the schedules the user has created for future use.
- The ability to add information whether an Employees holiday hours have been covered in the schedule.

# Limitations
This app will use local persistance, meaning the user of this app will have to create employee weekly templates and input holidays manually again if they switch to another machine, or if another user wishes to use this app on their personal device.

Furthermore, As the main priority of this app is for functional purposes and due to time constraints, the GUI will be minimalistic.

# Future additions
- A holiday schedule that displays a calendar of which employee has taken holidays and when, in one master schedule.

# Additional Info
This app has been created for the purposes of use for Pharma-Optima, and therefore the scope may be limited when applying the application to other workplaces / other uses.
